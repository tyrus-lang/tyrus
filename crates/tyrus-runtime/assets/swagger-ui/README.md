# Swagger UI

The files `swagger-ui-bundle.js` and `swagger-ui.css` are copied unmodified from the `swagger-ui-dist` package, version 5.32.15, published by SmartBear Software under the Apache License 2.0 (see `LICENSE` and `NOTICE`). The runtime embeds them to serve the page `app.docs()` enables, so the documentation works without reaching a third-party server.

To update, replace both files with the ones from a newer `swagger-ui-dist` release, together with its `LICENSE` and `NOTICE`, and change the version above.
