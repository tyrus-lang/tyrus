# Security Policy

## Supported versions

The latest stable release is the primary supported version for security fixes. Pre-release versions are provided for evaluation and may not receive security fixes. Check the release notes for the status of a specific version.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [tyrus@tyruslang.org](mailto:tyrus@tyruslang.org). Do not disclose the issue in a public issue, discussion, pull request, or other public channel before maintainers have had a reasonable opportunity to investigate and prepare a fix.

Include the affected Tyrus version, the relevant platform and configuration, steps to reproduce the issue, and its potential impact. Redact passwords, access tokens, personal information, and other secrets from reports and attachments.

The maintainers will make a reasonable effort to acknowledge the report, investigate it, and coordinate any public disclosure with the reporter. Please allow time for investigation and remediation before sharing vulnerability details publicly.
