# minCostMaxFlow

`minCostMaxFlow(edges, vertexCount, source, sink)` augments residual paths with costs and returns total flow and total cost.

| Signature | Returns | Complexity |
|-----------|---------|------------|
| `minCostMaxFlow(edges: [usize, usize, i32, i32][], vertexCount: usize, source: usize, sink: usize)` | `[i32, i32]` | O(FVE) |
