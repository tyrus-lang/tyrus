# zAlgorithm

Returns a `usize[]` where each position stores the length of the longest prefix of the input that starts at that position. The first value is always zero.

<!-- @include: ../../.fragments/modules/algorithm/z-algorithm/zalgorithm.md -->

## Study result

<!-- @include: ../../.fragments/modules/algorithm/z-algorithm/study-result.md -->

The algorithm runs in O(n) time and uses O(n) space for the result.
