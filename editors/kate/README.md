# Kate (KDE Advanced Text Editor)

Kate uses LSP for language intelligence and XML-based syntax definitions for highlighting.

## Files

- `tyrus.xml`, syntax highlighting definition (generated by `cargo run -p xtask`, do not edit manually)
- LSP config, a JSON file in the user's Kate config directory (see `docs/tooling/lsp.md`)

## Install

1. Copy `tyrus.xml` to the syntax directory for your platform (see `docs/tooling/lsp.md` for paths)
2. Add the LSP configuration to `~/.config/kate/lspclient/settings.json`
3. Restart Kate

## Regenerating

The `tyrus.xml` file is generated from `tyrus_core::keywords` by the xtask crate. To regenerate after adding or removing keywords:

```bash
cargo run -p xtask
```

To verify the file is up to date:

```bash
cargo run -p xtask -- --check
```

## Syntax highlighting

Kate uses KDE's syntax highlighting framework. The `tyrus.xml` file defines keywords, types, literals, comments, strings, numbers, decorators, and the topic token `%`.

After installing or updating the file, restart Kate. If a `.tyr` file is already open, go to **Tools > Editing Tools > Refresh Syntax Highlighting** and confirm that its highlighting mode is **Tyrus**.
